# Exercise Tracker

API for a simple exercise tracker to log the date and duration of your exercises. Keeps track of multiple users by username.

View the [live project](https://exercise-tracker-kaylam.glitch.me/).

This is a REST API project, part of [Free Code Camp's curriculum](https://www.freecodecamp.org/certification/kaylamoorcroft/back-end-development-and-apis). A base project was provided and I only modified the following files: index.js, package.json, README.md
